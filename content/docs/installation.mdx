## Requirements

- iPhone running iOS `18` or newer.
- Roughly `1.2 GB` of free storage for the local model weights.
- A Wi-Fi connection for the first run only. Inference runs offline afterwards.

Lumen does not ask for an Apple ID, email, or phone number. There is no onboarding to click through and nothing to sign in to.

## Install

Download the most recent `.ipa` from the [Releases](https://github.com/Lux-Softworks/Lumen/releases) page on GitHub and install it through TestFlight or your preferred sideloading tool. An App Store build is on the roadmap; until it lands, GitHub is the canonical channel.

If you prefer to build from source, see the [Contributing](/contributing) page.

<Callout type="info">
  You can browse without the model. The Ask panel will be inert until the
  download completes, but the reader, library, and privacy features all work
  immediately.
</Callout>
